# Aegean-Man

A lightweight browser arcade game set over a real Greece/Türkiye coastline map.

- Crescent-and-star arcade runner
- Greek flag collectibles
- Real coastline geometry used as the background map
- Neon maze routes and moving storm hazards
- Keyboard + mobile touch controls
- Score, level progression and local high score
- Zero dependencies, static deployment, Vercel-ready

## Run locally

Open `index.html` through any local static server, for example:

```bash
python3 -m http.server 8080
```

Then visit `http://localhost:8080`.

## Deploy

The repository is intentionally static. Vercel can deploy it directly with no build command.
